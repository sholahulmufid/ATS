LANGKAH BERIKUTNYA

Hubungkan ke ESP32.

Dashboard ini sudah memisahkan data simulasi dan pembacaan perangkat. Panduan menjelaskan file, alamat API, dan format data yang perlu disesuaikan.

  1. Siapkan API pembacaanESP32 atau gateway mengirim data sensor dalam format JSON.
  2. Ubah konfigurasi koneksiGanti mode demo, alamat API, dan interval pembaruan di config.js.
  3. Uji data sebelum kontrolMode perangkat menampilkan data sensor. Kontrol relay perlu integrasi firmware terpisah.
